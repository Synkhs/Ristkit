Aviso de privacidad

Última actualización: 16 de octubre de 2026

Resumen en una frase

RistKit Studio no tiene servidor propio: no crea cuentas, no recoge datos personales y no usa cookies de seguimiento. Todo lo que guardas (juegos, ajustes, API key) se queda en el localStorage de tu navegador y solo tú puedes leerlo.

1. Responsable

Esta web es operada por RistKit Entertainment (proyecto independiente). Para cualquier consulta sobre privacidad puedes contactar a través del formulario de feedback del estudio o del repositorio del proyecto.

2. Qué datos guardamos (y dónde)

Usamos exclusivamente el almacenamiento local del navegador (localStorage). No hay base de datos ni backend:

Clave en localStorageContenidoFinalidad
ristkit_games_v1Tus juegos guardados (nombre y código)Mostrarlos en tu arcade personal
ristkit_editor_autosaveBorrador automático del editorRecuperar tu trabajo si cierras la pestaña
ristkit_ai_settingsProveedor de IA, modelo, ajustes y tu API keyConectar el asistente con tu proveedor
ristkit_ai_chatHistorial de conversación con la IAConservar el chat entre sesiones
rk_snake_best, rk_dash_best, rk_mem_bestRécords locales de los juegos incluidosMostrar tu mejor puntuación

Tu API key nunca se envía a nuestros servidores (no existen): viaja directamente desde tu navegador al proveedor que elijas (OpenRouter, OpenAI, Anthropic, Groq, Mistral, DeepSeek o una URL personalizada). Puedes borrarla en cualquier momento con el botón «Borrar mi API key» del asistente o borrando los datos del sitio del navegador.

3. Aislamiento de los juegos

El código que ejecutas (juegos del editor, juegos guardados y juegos compartidos por terceros) se ejecuta dentro de un <iframe> con sandbox="allow-scripts" sin allow-same-origin. Esto significa que ese código no puede leer el localStorage de la página principal (donde está tu API key), ni tus juegos guardados, ni hacer peticiones con tus credenciales.

4. Servicios de terceros

  • Google Fonts (fuentes): puede registrar tu IP según su política. Alternativa: usar las fuentes del sistema (solo cambia el aspecto).
  • Proveedores de IA: solo reciben los mensajes que envías desde el chat, con la key que tú proporcionas. Consulta la política de cada proveedor.
  • jsDelivr / unpkg (CDN): pueden servir librerías del editor (CodeMirror) en futuras versiones; reciben tu IP al descargarlas.

5. Tus derechos (RGPD)

Al no tratar datos personales en servidores, el ejercicio de derechos (acceso, rectificación, supresión, portabilidad) se reduce a tu navegador: puedes exportar tus juegos desde el editor y borrar todo el almacenamiento de la web desde la configuración de tu navegador (Configuración → Privacidad → Datos de sitios). Al borrarlo, se eliminan juegos, ajustes, chat y API key de forma irreversible en ese dispositivo.

6. Menores de edad

El servicio no está dirigido específicamente a menores de 14 años y no recogemos conscientemente sus datos.

7. Cambios en este aviso

Si en el futuro se añaden funciones con servidor (cuentas, galería pública), se solicitará consentimiento explícito y se actualizará este documento antes de activarlas.
