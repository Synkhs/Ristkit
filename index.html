mi-juego.html — esqueleto mínimo 
<!-- Esqueleto de un juego HTML -->
<canvas id="game" width="480" height="360"></canvas>
<script>
  const ctx = document.getElementById("game").getContext("2d");
  let x = 40;

  function update() {
    ctx.clearRect(0, 0, 480, 360);
    ctx.fillStyle = "#a855f7";
    x = (x + 2) % 480;              // se mueve solo
    ctx.fillRect(x, 160, 50, 50);
    requestAnimationFrame(update);
  }
  update();
</script>
¿Qué es un juego HTML?

Es un juego hecho solo con las tecnologías nativas del navegador: HTML para la estructura, CSS para el estilo y JavaScript para la lógica.

  • No necesitas instalar nada: se abre con doble clic.
  • Funciona en móvil, tablet y escritorio.
  • Se puede subir a cualquier hosting (GitHub Pages, itch.io...).
  • El lienzo principal es la etiqueta <canvas>.
El bucle de juego

Todos los juegos repiten lo mismo 60 veces por segundo con requestAnimationFrame:

  • Input: lee teclado, ratón o táctil.
  • Update: mueve jugadores, verifica colisiones, suma puntos.
  • Draw: borra el canvas y vuelve a dibujar.

Ese ciclo es el game loop. Sin él, nada se movería.

Colisiones básicas

La más común es AABB (rectángulos que se solapan):

if (a.x < b.x + b.w && a.x + a.w > b.x &&
    a.y < b.y + b.h && a.y + a.h > b.y) {
  // ¡hay colisión!
}

Para círculos, compara la distancia entre centros con la suma de radios usando Math.hypot().

Controles y entrada
  • Teclado: escucha keydown / keyup y guarda el estado en un objeto.
  • Ratón: usa mousemove sobre el canvas (ajusta la escala con getBoundingClientRect()).
  • Táctil: touchstart / touchmove y no olvides preventDefault().
  • Guarda récords con localStorage como hacen nuestros juegos.
Exportar y publicar

Un juego HTML es un solo archivo: tu navegador es el motor.

  • Descargar desde el editor obtiene el .html listo.
  • itch.io: crea una página y sube el archivo (o un ZIP).
  • GitHub Pages: súbelo a un repositorio y actívalo en Settings.
  • Para móvil, añade <meta name="viewport"> y eventos táctiles.
